# Sound effects

Sound effects are downloaded from [Mixkit](https://mixkit.co/free-sound-effects/) and bundled for offline use under the [Mixkit Sound Effects Free License](https://mixkit.co/license/#sfxFree). File names are Mixkit's sound effect IDs. Attribution is not required by Mixkit, but is provided here.

Start of day uses Mixkit’s Morning birds (2472); Night falls uses Horror ambience (2482). Personalised player narration is still a placeholder.
